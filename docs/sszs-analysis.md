# SSZS 遗留系统分析

本文档总结了对 SSZS（赛事助手）Windows 桌面程序的分析，作为 PaddlePal 功能开发的参考。

## 参考赛事

**2026年漳浦县「庆元宵」乒乓球个人排名赛**
- 时间：2026年2月28日 - 3月1日
- 地点：乒协球馆（6台）
- 项目：甲组、乙组、丙组、女子组单打
- 赛制：第一阶段分组循环 → 第二阶段淘汰赛

## SSZS 主要模块

### 1. 规划面板
- 项目配置（单打/双打/团体）
- 阶段设置：循环赛、淘汰赛、附加赛
- 每组人数/队数
- 晋级规则
- 起始名次配置

### 2. 抽签面板
- 分组循环抽签
- 手工入位
- 自动抽签
- 种子位设置
- 同队合理分开
- 打印抽签结果

### 3. 编排面板
- 生成赛程
- 场地/时间分配
- 导出Excel
- 导入/导出模板
- 复制/粘贴赛程

### 4. 控场面板
- 实时监控所有球台（6台）
- 调场
- 成绩录入
- 检录管理
- 生成记分单
- 比赛状态跟踪

### 5. 赛程面板
- 按日期/时间/台次查看
- 按项目/阶段筛选
- 按组别/轮次颜色标记

### 6. 查询面板
- 按运动员姓名查询
- 按项目查询
- 比赛历史记录

## 成绩录入界面

### 主要元素
- 场次号：如 90071
- 球台：1-6
- 日期：2026-2-28
- 时间：8:30
- 双方运动员：陈国荣 vs 林思琪
- 大比分：3:1
- 局分：11-9, 11-8, 9-11, 11-3

### 快捷输入格式
连续数字输入：`1109110809111110`
- 解析为：11-09, 11-08, 09-11, 11-10
- 系统自动识别胜方

### 操作按钮
- 保存(S)
- 清成绩(C)
- 上一场(P)
- 下一场(N)
- 换主客(W)
- 计分单(□)
- 裁判长签单(E)

### 弃权选项
- ☐ 左弃权(L)
- ☐ 右弃权(R)

## 对 PaddlePal 的启示

### 需要实现的优先功能

1. **规划模块**
   - 项目/阶段配置
   - 组数和晋级规则
   - 每组人数设置

2. **抽签模块**
   - 分组循环抽签
   - 种子位设置
   - 同队分开算法
   - 手工调整功能

3. **编排模块**
   - 自动生成赛程
   - 球台/时间段分配
   - 贝格尔/ITTF轮转支持
   - 导出Excel/PDF

4. **控场模块**
   - 多球台实时视图
   - 快速比分录入（连续数字）
   - 调场功能
   - 裁判长确认流程

5. **导出模块**
   - 秩序册
   - 成绩册
   - 记分单（批量打印）
   - PDF生成

### 比分录入增强
- 支持快捷输入格式：`1109110809111110`
- 自动解析和验证比分
- 裁判长确认开关
